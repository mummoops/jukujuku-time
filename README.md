# JukuJuku Time

세이렌이 일하는 동안 친구들이 다시마에 매달려 숙성돼요.  
바탕화면에 캐릭터가 매달리는 Mac용 집중 타이머예요.

## 받기

**[JukuJukuTime.dmg 내려받기](https://github.com/mummoops/jukujuku-time/releases/latest/download/JukuJukuTime.dmg)**

1. DMG를 열고 `JukuJuku Time`을 `Applications`(응용 프로그램) 폴더로 끌어다 놓기
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 응용 프로그램 폴더에서 앱을 **우클릭 → 열기 → 열기**
   (macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 **그래도 열기**)

## 업데이트

새 버전이 나오면 앱이 알아서 알려줘요. **지금 업데이트**를 누르면 끝! (숙성 기록과 설정은 그대로)  
메뉴 막대 아이콘 → **업데이트 확인…** 으로 직접 확인할 수도 있어요.

macOS 14 이상 · Apple Silicon / Intel

## 이용 안내

JukuJuku Time은 팬이 취미로 만든 비공식 프로그램이에요. 원작 및 공식 관계사와는 관련이 없으며, 캐릭터를 비롯한 콘텐츠의 권리는 모두 원래 권리자에게 있습니다.

권리자 측에서 연락을 주시면 내용을 확인한 뒤 수정하거나 내리는 등 필요한 조치를 빠르게 하겠습니다.
